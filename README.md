# Teste Frontend Plan Marketing

Deploy disponível no link: **[plan-frontend-test](https://cva.style/docs)**

## Como executar local

```
npm install
npm run dev
```

## Bibliotecas

* **[class-variance-authority](https://cva.style/docs)** - Usado para definir variações para os componentes de forma mais organizada

* **[clsx](https://www.npmjs.com/package/clsx)** - Para facilitar o uso condicional de classes nos componentes
* **[tailwind-merge](https://www.npmjs.com/package/tailwind-merge)** - Facilidade o merge entre classes tailwind e evitar conflitos entre elas.
